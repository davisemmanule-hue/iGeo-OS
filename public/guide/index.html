0Daily Command Center

Purpose

Begin and end each workday from current saved records without duplicating opportunity data.

Daily startup routine

  1. Open iGeo Operator Dashboard.
  2. Click Acquisition OS.
  3. Click Morning Brief.
  4. Review Recommended first task, Current Active Opportunity, and Current Stage.
  5. Click Open Recommended First Task, Open Current Opportunity, or Resume Last Opportunity.
  6. Review Today's Startup Checklist.
  7. Click Opportunity Intelligence; review Last Updated, Last Successful Collection, Connected Sources, and Manual Review Sources.
  8. Click View Source Registry. Use Refresh Sources only to request current source status.

Daily shutdown checklist

2Workspace Reference

Only visible production workspaces and controls are listed. Controls appear when their related record or state is available.

Today

Purpose: Operator start page. Navigation: root URL or Return to Operator Dashboard. Visible controls: global search, Today, Acquisition OS, Contacts, Quotes, Applications, Registrations, Capability Statements, Settings, Open Proposal Workspace, Current opportunity, How to Use iGeo OS, checklist actions, Simple Work, Controls, and Operator Settings. Expected result: business-wide work is visible. Troubleshooting: return to the root URL if a workspace query remains in the address.

Acquisition OS — Bid Engine Dashboard

Navigation: click Acquisition OS, then Bid Engine. Header buttons: Return to Operator Dashboard, Open Full Bid Engine, CSV Export, Opportunity. Cards: Active Bids, Ready to Submit, Waiting on Pricing, Waiting on Documents, Waiting on Subcontractor, Submitted, Awards Pending, Estimated Pipeline, Potential Gross Profit. Expected result: each card opens its existing workspace.

Morning Brief

Navigation: Acquisition OS → Morning Brief. Buttons: Export backup, Open Recommended First Task, Open Current Opportunity, Resume Last Opportunity, actionable metric cards. Widgets: Recommended first task, Current Active Opportunity, Current Stage, Today's Startup Checklist, new/high-priority opportunities, deadlines, registrations, documents, suppliers, subcontractors, proposals, pipeline, and gross profit. Expected result: saved data determines the first action. Troubleshooting: “No priority task” means current records do not produce one.

Opportunity Intelligence and Source Registry

Navigation: Acquisition OS → Opportunity Intelligence. Buttons: Manual entry, Collect now, Refresh Sources, View Source Registry, Verify, Approve For Pipeline, Reject, Archive, Open Official Source, Open Attachments, Add Notes. Search and filters: opportunity search, state, match, status, type, minimum value, source, region, service, verification status. Widgets: Last Updated, Last Successful Collection, Connected Sources, Manual Review Sources, collection metrics. Expected result: one canonical opportunity is retained. Troubleshooting: SAM.gov connection not configured is the safe no-key state; never treat Manual Review Required as Connected.

Opportunity Dashboard

Navigation: Acquisition OS → Opportunity Dashboard. Quick filters: All, Due Today, Due This Week, Pursue Immediately, Subcontract, Ready to Submit, Submitted, Awarded. Fields: Search Opportunities, Decision, Performance Method, NAICS, Service. Table: Opportunity, Service / NAICS, Region, Score, Decision, Performance, Deadline, Contact. Expected result: filters change the visible existing records only.

Documentation Library

Navigation: Acquisition OS → Documentation Library. Buttons: Add document, Download, New version, Delete, Save, Cancel. Fields: Search name, tag, category; All folders; Name; Folder; Tags; File; Notes. Expected result: document records remain searchable. Troubleshooting: browser-local files require a backup outside the browser.

Procurement Calendar

Navigation: Acquisition OS → Procurement Calendar. Buttons: Add event, Month, Week, List, Previous month, Next month, event, Save, Delete, Cancel. Widgets: Today's Events, This Week, Overdue, Completed. Fields: Event, Date, Type, Color, Complete. Expected result: clicking a day opens List filtered to that date; clicking an event opens its edit dialog; completed and overdue states use existing records.

Proposal Versions

Navigation: Acquisition OS → Proposal Versions. Buttons: Compare, Restore. Expected result: versions reference the same proposal and canonical opportunity. Troubleshooting: verify the opportunity and version before Restore.

Registration Center

Navigation: Acquisition OS → Registration Center. Buttons: Start Registration, Continue, Mark Complete. Search and filters: portal or state and All statuses. Cards: portal, status, progress, renewal, documents, password hint. Expected result: progress and renewals remain tied to existing registration records. Troubleshooting: never store a password in Password hint.

Product Brokerage

Navigation: Acquisition OS → Product Brokerage. Buttons: Add supply opportunity, Add supplier. Tabs: Opportunities, Suppliers, Calculator. Expected result: existing supplier, cost, price, margin, risk, and decision data are used.

Expected result: every tool operates on the selected opportunity. Recon buttons open external searches and do not modify data. Contacts, Quotes, Applications, Registrations, Capability Statements, Settings

Navigation: use the matching top navigation item on Today. Purpose: Contacts opens Prime Contractor CRM; Quotes opens quote records; Applications opens Workforce Management; Registrations opens vendor registration records; Capability Statements opens capability statement records; Settings opens Operator Settings. Search/fields/tables: use only those visible in the selected workspace. Expected result: existing records open without creating Acquisition OS duplicates.

Global Search and Command Palette

Navigation: click the global search or press Ctrl + K on Windows / Cmd + K on Mac. Search: opportunities, prime contractors, contacts, registrations, calendar events, proposals, subcontractors, capability statements, NAICS, and suppliers. Expected result: selecting a result opens its existing workspace or record.

Exports

CSV Export exports Acquisition opportunity data. Word and PDF are Full Bid Engine exports. Export backup exports saved Acquisition OS data. Confirm the correct opportunity before exporting.

3Click-by-Click Procedures

Capture Opportunity

  1. Click Acquisition OS.
  2. Click Opportunity Intelligence.
  3. Click Manual entry.
  4. Complete the visible opportunity fields from the official notice.
  5. Click Save.
  6. Open the saved record and click Open Official Source.
  7. Click Verify.
  8. Click Approve For Pipeline only after verification.

Analyze, score, and decide

  1. Click Open Full Bid Engine.
  2. Select the opportunity.
  3. Click Bid Engine.
  4. Expand Thinker's Recon.
  5. Complete the recon fields, checklist, Recommended Performance Method, and Operator Decision.
  6. Use the external search buttons when research is required.
  7. Check Recon Complete.
  8. Click Solicitation Analyzer.
  9. Review the official scope, instructions, documents, and requirements.
  10. Click Opportunity Scoring Engine.
  11. Review fit, risk, subcontractability, brokerability, urgency, and recommendation.
  12. Click Bid Engine.
  13. Record the pursuit decision.

Compliance, proposal, and pricing

  1. Click Compliance Checklist Generator.
  2. Check an item only when evidence supports it.
  3. Click Proposal Draft Generator.
  4. Complete and review the visible proposal sections.
  5. Click Pricing Worksheet.
  6. Click ＋ Line for each pricing line.
  7. Verify labor, supplies, partner margin, overhead, profit, and total.
  8. Click Save.

Submission and follow-up

  1. Click Final Submission Review.
  2. Complete every visible confirmation checkbox.
  3. Click Open Submission Portal when available.
  4. Submit through the official portal.
  5. Complete Date, Time, Confirmation Number, Submitted By, Method, Notes, and Follow Up Date.
  6. Click Save.
  7. Use Procurement Calendar and Procurement Contact Database for saved follow-up actions.

Calendar

  1. Click Procurement Calendar.
  2. Click Add event.
  3. Complete Event, Date, Type, Color, and Complete.
  4. Click Save.
  5. Click an event to edit it.
  6. Check Complete and click Save when finished.

Registration, documents, and product brokerage

  1. Click Registration Center; click Start Registration or Continue; click Mark Complete only after confirmation.
  2. Click Documentation Library; click Add document; complete Name, Folder, Tags, File, and Notes; click Save.
  3. Click Product Brokerage; click Add supply opportunity or Add supplier; use Calculator to verify existing cost and profit inputs.
4Troubleshooting
Navigation opens the wrong place
Use the visible sidebar item, confirm the workspace query in the address, and use browser Back/Forward. Bid Engine opens the Acquisition OS dashboard; Open Full Bid Engine enters the proposal system.
Search returns nothing
Clear the query and filters. Confirm that the record exists in the relevant workspace. Press Escape to close the command palette.
Workspace does not scroll
Place the pointer inside the bordered right-side workspace. Use its visible scrollbar. On mobile, use touch scrolling inside the active workspace.
Calendar item is missing
Check Month, Week, and List; navigate to the correct month; clear a day-specific List selection by selecting another view.
Bid Engine record is not selected
Return to Opportunity Dashboard, select the opportunity, then reopen the required Full Bid Engine workspace.
Thinker's Recon notes are missing
Confirm the correct opportunity is selected in Full Bid Engine. Recon notes are stored on that existing opportunity and do not create a separate record.
Opportunity Intelligence source is not connected
Review the exact Source Registry status. Manual Review Required requires the official portal. SAM.gov requires the server-side key; no-key operation remains available.
Morning Brief has no task
No current saved record produced a priority task. Review Opportunity Intelligence and the Calendar.
Browser data appears different
Confirm the same browser/device is being used. Browser-local records do not automatically move between devices unless supported by the existing cloud synchronization for that record type.
Mobile or desktop layout issue
Reload once, use current browser zoom, and confirm no stale cached page remains. Do not delete browser data unless a verified backup exists.
Recovery
Use a valid Export backup. Never overwrite newer verified records without comparing them first.
