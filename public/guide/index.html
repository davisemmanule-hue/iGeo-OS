1Dashboard Overview

Operator Dashboard

The main dashboard remains the starting point for daily work, CRM, Workforce, Quotes, Registrations, Capability Statements, alerts, and settings.

  1. Open igeosolutionsllc.com.
  2. Select Acquisition OS to open the Bid Engine Dashboard.
  3. Use Today to return to the operator dashboard.
2Sidebar Navigation

The Acquisition sidebar stays visible on desktop while the selected workspace scrolls independently. Each item opens one workspace and updates the browser address.

  1. Select a sidebar item to open it directly.
  2. Use browser Back and Forward to revisit prior workspaces.
  3. On mobile, swipe or scroll through the compact navigation and then work in the page below it.
3Opportunity Dashboard

This is the operational command center for opportunities only.

  1. Open Opportunity Dashboard.
  2. Search or filter opportunities by decision, performance method, NAICS, and service.
  3. Review scores, recommendations, pipeline status, deadlines, contacts, and available actions.
  4. Use Opportunity in the page header for manual entry.
4Morning Brief

Morning Brief is the single acquisition start page. It shows only actionable counts derived from saved records: new and high-priority opportunities, deadlines, expiring registrations and documents, supplier quotes, subcontractor needs, proposal review, submission readiness, pipeline, and potential gross profit. Select a card to open the related workspace. Use Export backup before major data changes.

5Documentation Library
  1. Open Documentation Library.
  2. Use Search and Folder filters for Corporate, Financial, Proposal, or Operations records.
  3. Select Add document, enter name, folder, tags, notes, and an optional file.
  4. Use Download, New Version, or Delete on the correct record. File storage is local to this browser.
6Procurement Calendar
  1. Open Procurement Calendar.
  2. Switch among Month, Week, and List/Agenda views.
  3. Select Add event for deadlines, site visits, questions, renewals, insurance expiration, or SAM renewal.
  4. Opportunity deadlines and registration renewals appear automatically when saved data contains dates.
7Proposal Versions
  1. Open Proposal Versions.
  2. Versions reference the same canonical opportunity used throughout Acquisition OS.
  3. Select Compare to review the selected snapshot against the prior version.
  4. Select Restore only after confirming the correct opportunity and version.
8Vendor Registration Center
  1. Open Registration Center.
  2. Search or filter Federal, State, Commercial, Completed, renewal, and progress records.
  3. Select Start Registration or Continue to update progress.
  4. Review required documents, renewal date, password hint, and status. Never store an actual password.
  5. Select Mark Complete only after portal confirmation.
9Supply & Product Brokerage
  1. Open Product Brokerage.
  2. Use Opportunities for sourcing, manufacturer/distributor, margin, working-capital, risk, and decision analysis.
  3. Use Suppliers to search manufacturers, distributors, categories, service regions, authorization, and rating.
  4. Use Calculator for revenue, cost, shipping, taxes, fees, gross profit, margin, and working capital.
10Opportunity Intelligence
  1. Open Opportunity Intelligence.
  2. Review search, filters, match label, shared fit score, recommendation, risks, and requirements.
  3. Use Manual Entry when a public source is unavailable; duplicate identity is checked against the canonical opportunity store.
  4. Collection shows SAM.gov connection not configured when the server-side key is absent; existing manual tools continue working.
11Search

Use the top universal search for companies, opportunities, buyers, agencies, workers, NAICS, PSC, cities, and indexed modules. Each dedicated workspace also provides its own search or view controls.

12Unified Workflow

One opportunity record

  1. Start with the Morning Brief and open the highest-priority record.
  2. Verify the opportunity once in Opportunity Intelligence or Opportunity Dashboard.
  3. Use the shared score and recommendation for the pursue decision.
  4. Confirm registrations and linked documents.
  5. Use Full Bid Engine for analysis, compliance, proposal, pricing, and subcontractor work.
  6. Use Proposal Versions and the derived Calendar deadlines.
  7. Update CRM and pipeline status, complete submission review, then record submission.

Opportunity title, buyer, solicitation number, deadlines, and related status should be referenced from the existing record rather than retyped.

13Mobile Navigation
  1. Open Acquisition OS.
  2. Use the compact sidebar navigation to select one workspace.
  3. Scroll the workspace vertically; cards and controls stack for touch use.
  4. Use browser Back to return to the prior workspace. Tables scroll only inside their table containers.
14Frequently Asked Questions
Where did the long Acquisition page go?
It was replaced by dedicated workspace routes. No business data was removed.
Where are opportunity scores and recommendations?
Open Opportunity Dashboard or Opportunity Intelligence.
Where is the Acquisition OS Bid Engine Dashboard?
Select Bid Engine in the Acquisition OS sidebar.
Where is the complete proposal workflow?
Use Open Full Bid Engine from the Acquisition header.
How do I leave the Full Bid Engine?
Select Return to Operator Dashboard to open the Today dashboard.
Does Back work?
Yes. Workspace selections are stored in browser history.
Is existing data preserved?
Yes. Existing local storage keys and record schemas remain in place.
Why is SAM.gov not connected?
The optional API key has not been configured server-side. Manual entry, search, filters, scoring, and recommendations remain available.
